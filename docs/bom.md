# BOM:

This design requires 2 extruders.  It accommodates either Orbiter v2 / v2.5 or BMG (and clones).  I used Orbiter extruders for my 600x600x650mm printer because I wanted the increased component quality and reliability for a printer that mostly prints multi-KG parts. I used BMG clones to cut costs for a smaller printer that mostly prints sub-1KG parts.  Either way, you'll need to select and source two extruders that match either Orbier or BMG dimensions.

It can also be helpful to have a set of taps (M2, M2.5 and M3) but these are not required.   The taps make it easier to start the self-tapping screw holes.

You'll also need to make custom cables using crimpers, etc.  There are Dupont connects and JST-XH connectors used in the build.  Mostly just JST to JST for which you can purchase premade wires if necessary.

## Main components:

### Electronics

* **1x** BTT SKR-Pico controller ([amazon](https://www.amazon.com/dp/B09MYKL9MP?ref_=ppx_hzsearch_conn_dt_b_fed_asin_title_1&th=1))
* **1x** 24V 3A power supply
* **2x** Neopixel breakout board ([amazon](https://www.amazon.com/dp/B0B73LTNNB?ref_=ppx_hzsearch_conn_dt_b_fed_asin_title_2))
* **2x** Extruder (BMG clone or ideally Orbiter v2.5)
* **1x (optional)** low profile 90 degree USB cable ([amazon](https://www.amazon.com/dp/B0CCJLS4R5?ref_=ppx_hzsearch_conn_dt_b_fed_asin_title_1&th=1))

### Hardware

* **1x** Spring: 1/2" x 1 1/2" x 1mm ([amazon](https://www.amazon.com/dp/B09N6NJR3B?ref_=ppx_hzsearch_conn_dt_b_fed_asin_title_1&th=1))
* **2x** D2F-L switches ([amazon](https://www.amazon.com/dp/B0D54J5D82?ref_=ppx_hzsearch_conn_dt_b_fed_asin_title_1))
* **5x** D2F switches: if you have to purchase these, just use the D2F-L switches and remove the lever from them.
* **5x** MR-63ZZ bearings ([amazon](https://www.amazon.com/dp/B0DY1DPCJ4?ref_=ppx_hzsearch_conn_dt_b_fed_asin_title_1&th=1))
* **1x** DC through hole jack (11mm mounting hole) ([amazon](https://www.amazon.com/dp/B0DLKN8J7M?ref_=ppx_hzod_title_dt_b_fed_asin_title_3_0)
* **8x** ECAS-04 PTFE Connectors ([amazon](https://www.amazon.com/dp/B099NPWSFB?ref_=ppx_hzsearch_conn_dt_b_fed_asin_title_1))
* **8x** M3 heatset inserts (Voron style: 5x3x4 mm)
* 2.5mm ID 4mm OD PTFE bowden tube (note that you will need the larger ID version -- 2.5mm -- and not the traditional 2mm ID tubing)
* M2 SHCS
* M2.5 SHCS
* M3 button head screw
* JST-XH and Dupont crimps and housings, wires, crimping tools, etc.
