# 3D Printed Parts

The parts are available on [Printables](LINK NEEDED) and [Maker World](LINK NEEDED).

## Filament

The parts can be printed in any filament.  All my prototypes were printed in PLA and the final versions were printed in PET-G.  I choose to use PET-G for the final parts because PET-G parts tend to have lower friction and I theorize that the slide will move a little easier in the filament buffer.  I never tested if this is the case or not but I would print in PET-G if that's filament that you have and are comfortable printing in.  If not, using PLA will be fine.

## Settings

All parts should be printed with **33% gyroid infill**, extra walls (**4 walls** for 0.4mm nozzles and **3 walls** for 0.6mm nozzles) and **alternate extra wall** if your slicer supports it.

## Parts

The only parts that you will need are:

* **infinite-feeder-body.3mf** should be oriented naturally (with the back on the build plate), no supports are needed.
* **infinite-feeder-top.3mf** make sure you add supports to the recessed screw holes
* **board-mount.3mf** obvious orientation, no supports are needed.
* **slide.3mf** the side with the directional arrows should be down on the build plate.  You will need to support the small wings used to guide the slide.  I use would use dedicated support filament if you are able.  The reason for this orientation is to ensure the bottom side of the wings is as smooth as possible for easy movement in the buffer.
* **3x** **inline filament sensors**
* '''(optional)''' **2x** **BMG extruder brackets**
